# CL005 — Type mismatch

- **Severity:** Error
- **Confidence:** follows the resolution of the binding site

## What it finds

A configuration value that cannot bind to the target property type of an options class registered via `Configure<T>(section)`, `section.Bind(…)` or `section.Get<T>()`.

## Why it matters

Options binding throws at startup — or worse, at first resolution of `IOptions<T>` — with an exception that names the property but not the file. ConfigLens points at the exact value in the exact file.

## Semantics

Checked property types: the numeric primitives, `bool`, `char`, `string`, `Guid`, `TimeSpan`, `DateTime`, `DateTimeOffset` and enums (validated against member names, case-insensitive, or numeric values). Values are parsed with the invariant culture, matching the runtime binder. Complex property types and empty values are skipped — no false certainty (ADR-0002). Every environment file is checked independently.

## Example

```jsonc
{
  "Server": {
    "Port": "not-a-number" // CL005: cannot bind to int ServerOptions.Port
  }
}
```

## How to fix

Fix the value, or change the property type. For values that are intentionally non-standard (custom `TypeConverter`), record the finding in the baseline.
